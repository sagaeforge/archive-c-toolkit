# NLB_Utility

각 라이브러리의 명칭 및 사용 방법.

GarbageCollection : Heap메모리를 효과적으로 관리하는 라이브러리
Operator          : 연산자 오버로딩 및 데이터 타입 관련 라이브러리
String            : 문자열을 효과적으로 사용할 수 있도록 돕는 라이브러리
DevelopGuide      : 개발을 하면서 불편한 점을 간단하게 해결하는 라이브러리 (에러처리 관련)
LinearDataTypes   : 선형 데이터 타입을 효율적으로 만들 수 있도록 만든 템플릿 라이브러리

# GarbageCollection 사용법
GC_Init() => Create => Remove => GC_Clean()
